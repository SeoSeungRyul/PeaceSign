채집은 거점 밖에서 재료를 얻고, 필요한 재료에 따라 다음 탐사 지역을 고르는 콘텐츠로 구성한다. 벌목은 건축·제작 재료, 열매는 탐사 식량, 약초는 회복·제작 재료, 발굴은 유물 수집을 담당한다. 첫 구현은 벌목과 흔들기를 완성하고, 같은 대상 판정·보상·저장 흐름에 식물과 발굴을 추가하는 순서가 적합하다.

## 원본 기준

- 농사 콘텐츠 해금 후 에반과 대화하면 채집이 해금된다.
- 나무 우클릭 시 도끼를 장착했으면 벌목, 그 외 장비는 나무 흔들기를 수행한다.
- 벌목은 타격 애니메이션의 타격 시점에 피해를 적용한다. HP가 남으면 보상 없이 다음 입력을 기다린다.
- HP가 0이 되면 쓰러짐 연출을 재생하고 추가 타격을 막는다. 수종에 맞는 원목과 씨앗을 드롭하고 나무 오브젝트를 제거한다.
- 흔들기는 나무를 유지하며 씨앗만 드롭한다. 보상 지급 후 해당 나무에 게임 시간 일주일의 쿨타임을 적용한다. 쿨타임 중에도 흔들기 연출은 가능하나 보상은 없다.
- 기본 나무 HP는 60이다. 도구 사용의 기본 SP 비용은 10이다.
- 나무 상태는 일반·그루터기·성장으로 구분한다.
- 드롭 확률과 수량은 데이터 시트에서 관리한다. 원본에는 수치가 기입되어 있지 않다.
- 열매·약초·발굴은 작성할 항목만 있고 종류·수량·시간·재생성의 구체 규칙은 아직 없다.

### 지역별 나무

| 지역 | 메인 | 서브 | 생성된 나무의 수종 선택 비율 |
| --- | --- | --- | --- |
| 초원 | 참나무 | 단풍나무 | 80% / 20% |
| 삼림 | 단풍나무 | 자작나무 | 80% / 20% |
| 꽃밭 | 벚나무 | 참나무 | 80% / 20% |
| 해안가 | 야자수 | 없음 | 야자수 100% 제안 |
| 사막 | 선인장 | 없음 | 선인장 100% 제안 |
| 눈 | 자작나무 | 단풍나무 | 80% / 20% |

80% / 20%는 나무가 놓일 위치를 정한 뒤 수종을 고르는 확률이다. 타일의 80%를 나무로 채우는 밀도로 사용하지 않는다. 서브가 없는 지역의 남은 20%를 빈칸으로 처리할지는 원본에 명시되어 있지 않아 메인 100%를 제안한다.

## 플레이 흐름 제안

탐사 → 대상과 가능한 행동 확인 → 짧은 작업 → 획득 표시 → 인벤토리·도감 확인 → 재료를 사용하거나 다음 지역 탐사로 이어진다. 별도 미니게임 없이 대상 반응과 도구 성장에서 손맛을 만든다.

### 입력과 대상 우선순위

우클릭한 위치의 채집 대상을 먼저 판정하고, 채집 대상이 없을 때 기존 농사·낚시·지형 도구 동작으로 넘긴다. 현재 코드는 괭이·낚싯대 동작을 먼저 실행하므로, 나무를 클릭했을 때는 도끼 외 장비가 모두 흔들기로 들어가도록 입력 분기 순서를 바꿔야 한다.

| 대상 | 입력 조건 | 수행 동작 |
| --- | --- | --- |
| 일반 나무 | 도끼 + 우클릭 | 1회 타격 |
| 일반 나무 | 도끼 외 장비 + 우클릭 | 흔들기 |
| 성장 중 나무·그루터기 | 우클릭 | 상태 안내, 작업·소모 없음 |
| 채집 가능한 열매·약초 | 맨손 + 우클릭 | 짧은 채집 동작 |
| 열매·약초 | 다른 장비 + 우클릭 | 맨손 채집 안내, 다른 도구 동작으로 넘기지 않음 |
| 발굴 흔적 | 삽 + 우클릭 | 발굴 |
| 발굴 흔적 | 다른 장비 + 우클릭 | 삽 필요 안내 |
| 채집 대상 없는 일반 땅 | 기존 도구 + 우클릭 | 기존 농사·삽·낚시 규칙 |

도구가 맞지 않거나 범위 밖인 채집 대상도 입력을 소비한다. 뒤에 있는 땅을 갈거나 발굴 흔적을 풀·흙으로 전환하지 않도록 한다. F는 기존 일반 상호작용으로 유지한다.

상호작용 범위는 기존 채광과 같은 직선 두 칸·대각선 한 칸을 제안한다. 물·벽·다른 큰 오브젝트 너머의 대상에는 작업할 수 없게 한다. 나무는 줄기 기준 셀로 선택하며 수관 그림이 인접 대상의 선택을 가리지 않도록 한다.

### 벌목과 흔들기

1. 해금·거리·대상 상태·장비 내구도·SP를 확인하고 대상과 도구를 고정한다.
2. 한 동작 동안 이동·연속 입력·장비 교체를 제한한다. 타격 전 취소되거나 대상이 사라지면 소모하지 않는다.
3. 타격 시점에 조건을 다시 검사하고 SP·내구도·HP 변경을 한 번만 적용한다. 이후 연출이 중단돼도 이미 적용한 타격은 유지한다.
4. 마지막 타격이면 추가 상호작용을 즉시 차단하고 쓰러짐 연출 후 보상을 드롭한다. 보상은 나무 1그루당 한 번만 확정한다.
5. 나무가 쓰러진 자리에는 제안한 그루터기 상태를 남긴다. 부분 피해·흔들기 쿨타임은 청크 이탈과 저장 후에도 유지한다.

**임시 밸런스 제안:** 타격 동작 0.6초, 흔들기 0.8초, 도끼 내구도 100, 유효 타격마다 내구도 1을 사용한다. 흔들기는 도구 사용이 아니므로 SP와 장비 내구도를 소모하지 않는 안을 제안한다. 원본의 SP 10을 흔들기에도 적용할지는 확인이 필요한 해석이다.

처음 생성된 성목은 즉시 흔들기 보상을 받을 수 있게 한다. 쿨타임은 보상이 확정된 시점부터 7×48=336개의 게임 시간 30분 구간으로 계산한다. 메뉴 일시정지에서는 흐르지 않고, 수면·개발용 시간 넘기기에는 경과를 반영한다. 흔들기 후 벌목해도 벌목 원목·씨앗 보상은 별개로 지급하는 안을 제안한다.

### 보상과 인벤토리

첫 테스트 수치는 **벌목 시 수종별 원목 3개 + 씨앗 1개, 보상 가능한 흔들기 시 씨앗 1개**를 제안한다. 모든 수종에 같은 값을 써서 행동·저장부터 검증하고, 생산량 차이는 플레이 확인 후 데이터로 조절한다.

원본의 드롭 연출을 살려 보상은 월드에 떨어뜨리고 가까이 가면 기존 월드 아이템의 수집 흐름으로 가방에 넣는다. 가방이 차면 아이템을 바닥에 유지한다. 쿨타임은 주울 때가 아닌 드롭 확정 시점에 갱신한다. 제작용 공통 목재가 필요하면 원목을 가공해 얻도록 하고, 6종 원목의 구분은 유지한다. 선인장은 원본의 별도 선인장 아이템으로 취급하고 목재 가공 가능 여부는 추후 정한다.

벌목 완료·보상이 발생한 흔들기·식물 채집 완료·발굴 완료를 각각 유효 행동 1회로 정의하고 경험치 2를 주는 안을 제안한다. 마지막 타격 이전, 쿨타임 중 흔들기, 실패·취소, 떨어진 아이템 줍기는 경험치를 주지 않는다. 가방 부족으로 드롭만 됐어도 성공 경험치는 지급한다. 별도 채집 분야 추가를 제안하며, 기존 농사·채광 분야에 임의로 합산하지 않는다.

### 제거와 재성장

원본에는 벌목 후 오브젝트 제거와 일반·그루터기·성장 상태가 함께 적혀 있어 연결 규칙이 필요하다. **성목 오브젝트를 제거하고 같은 자리에 그루터기 상태를 남기는 방식**을 제안한다.

| 상태 | 진입 | 행동·충돌 제안 | 다음 상태 |
| --- | --- | --- | --- |
| 일반 | 최초 생성 또는 성장 완료 | 벌목·흔들기 가능, 줄기 충돌 | HP 0이면 쓰러짐 처리 |
| 쓰러짐 연출 | 마지막 타격 | 중복 입력 차단, 보상 1회, 충돌 해제 | 그루터기 |
| 그루터기 | 벌목 완료 | 통과 가능, 경작·건설은 점유로 차단 | 게임 3일 후 성장 |
| 성장 | 그루터기 시간 만료 | 작업 불가, 통과 가능, 점유 유지 | 추가 게임 4일 후 일반 |

3일+4일과 충돌·점유 규칙은 제안값이다. 재성장 때 HP를 60으로 복구한다. 과거 흔들기 쿨타임은 별도로 유지하고, 재성장 자체가 씨앗을 지급하지 않는다. 그루터기 제거와 씨앗 심기는 이후 확장으로 남기며, 씨앗 설명에는 식재 기능이 구현된 이후에만 심기 안내를 표시한다.

## 식물과 고고학 확장 제안

| 콘텐츠 | 초기 역할 | 획득 동작 제안 | 초기 보상 제안 | 재생성 제안 |
| --- | --- | --- | --- | --- |
| 열매 | 탐사 중 식량 수급 | 맨손 0.6초, SP 0 | 열매 1~2개 | 덤불 유지, 게임 2일 후 결실 |
| 약초 | 회복·제작 재료 수급 | 맨손 0.8초, SP 0 | 약초 1개 | 지상부 제거, 게임 3일 후 재성장 |
| 발굴 | 유물 수집 | 삽 1.2초, SP 10, 내구도 1 | 유물 1개 | 지점 소멸, 게임 7일 후 지역 내 새 위치 후보 생성 |

이 표는 모두 신규 제안이다. 열매·약초는 지역별 대표 1종부터 시작하고, 계절 데이터는 필드를 마련한 뒤 실제 목록이 정해지면 적용한다. 발굴은 갈라진 땅·반짝임 등 눈에 보이는 흔적으로 표시하고, 보상 확률과 유물 목록이 정해지기 전에는 개발용 보상만 사용한다.

열매는 요리·허기 회복, 약초는 회복약 제작으로 연결한다. 초기에는 각 아이템에 최소 한 가지 실제 사용처를 함께 제공한다. 유물은 기존 도감의 유물 탭에 수집 기록을 연결하고 판매·전시는 경제·전시 시스템 구현 시 추가한다. 미구현 사용처를 아이템 설명에서 이용 가능한 기능처럼 안내하지 않는다.

새 발굴 후보는 물·돌·나무·작물·건물·통로·보호 영역과 겹치지 않게 한다. 유효 후보가 없으면 재생성을 보류한다. 미채집 흔적이 쌓이지 않도록 지역별 상한을 둔다. 식물의 재생성은 자정 일괄 초기화 대신 수확 시각부터 계산해 자정 직전·직후 연속 수확을 막는다.

## 월드 배치와 화면 안내 제안

실제 바이옴 생성기는 아직 없으므로 첫 단계는 테스트맵에 초원과 삼림 영역을 명시적으로 지정한다. 참나무·단풍나무부터 플레이를 검증하되 나머지 수종도 같은 데이터 구조를 사용한다. 해안·사막 등은 배치 규칙과 데이터 행부터 준비한다.

나무 위치는 월드 시드와 생성 규칙 버전으로 결정한다. 초기 밀도는 생성 가능한 육지 8×8칸당 3~5그루를 테스트값으로 제안한다. 거점 안전 반경, 필수 통로, 건물 보호 영역, 물, 돌, 작물과 겹치지 않고 줄기 사이를 최소 2칸 띄운다. 수관 이미지는 여러 칸을 덮을 수 있어도 줄기 점유는 기본 한 칸으로 시작한다. 통행 가능한 경로가 유지되는지도 확인한다.

대상을 가리키면 이름·가능한 행동·부족 조건을 표시한다. 나무 HP는 타격 중에만 보여주고, 흔들기 쿨타임은 해당 대상을 가리킬 때 남은 일·시간으로 안내한다. 획득은 작은 아이템 알림으로 표현하며 도감의 채집 탭에는 첫 원목·씨앗·식물 획득을 등록한다. 발굴물은 유물 탭에 기록한다. 낚시의 최대 크기·노란 별 규칙을 채집에 그대로 적용하지 않는다.

## 기존 코드에 연결할 구조 제안

현재 코드에는 돌 중심의 월드 오브젝트와 목재 아이템이 있고, 도끼·나무 상태·채집 경험치 분야는 없다. 삽 우클릭은 풀↔흙 변경 기능이며 발굴과 연결되어 있지 않다. 도감의 채집·유물 탭은 빈 화면이므로 실제 데이터 공급을 추가해야 한다.

| 영역 | 추가·연결 방향 |
| --- | --- |
| 장비 | `EPSEquipment`와 `EPSItemType`에 도끼 추가, 기존 저장 enum 값은 유지하며 끝에 추가 |
| 아이템 | `FPSItemStack.ItemId`로 수종별 원목·씨앗과 도끼 단계를 식별, 나무 씨앗은 작물 씨앗과 분리 |
| 수종 데이터 | 현재는 수종별 C++ 매핑과 Gathering의 TreeMaxHealth 설정을 사용한다. 이름·보상 정보는 Item·TreeCutDrop·TreeShakeDrop이 담당한다. 이전 수종 테이블 제안은 2026-11-02 정리 과정에서 대체했다. |
| 도끼 데이터 | `DT_Axe`: 단계, 피해량, SP, 내구도, 추가 목재·희귀 보상 확률 |
| 생성 데이터 | `DT_GatheringSpawn`: 지역, 수종 가중치, 밀도, 간격, 보호 영역 규칙 |
| 식물·발굴 | 별도 데이터 행에서 작업 시간·필요 장비·보상·재생성 규칙 정의 |
| 월드 상태 | `EPSWorldObjectType` 확장과 청크별 채집 자원 기록으로 지형·자원 상태 분리 |
| 입력·행동 | `PSPlayerController`에서 대상 우선 분기, 별도 채집 행동 컴포넌트에 작업 시작·판정·완료 위임 |
| 렌더링 | 줄기 충돌과 수관 이미지를 분리, 쓰러짐·흔들기는 인접 청크 상태에도 일관되게 반영 |
| 시간·저장 | `UPSGameTimeSubsystem`의 누적 게임 시간과 `PSWorldSaveGame` 청크 저장을 확장 |
| 도감 | 기존 책 배치를 유지하고 채집·유물 분류에 실제 목록과 발견 상태 연결 |
| 성장 | 기존 스킬 enum 끝에 채집 분야 추가, 성공 행동별 경험치 데이터 연결 |

나무의 최소 저장 항목은 자원 ID, 기준 셀, 수종, 현재 상태, 남은 HP, 다음 상태 전환 시각, 다음 흔들기 보상 가능 시각, 확정한 보상 처리 정보다. 자원 ID는 재접속·청크 재로드에도 바뀌지 않아야 한다. 인스턴스나 액터는 화면 표현을 담당하며 액터가 사라져도 자원 상태는 청크에 남긴다.

기존 월드에는 별도 채집 생성 버전을 도입한다. 방문한 청크에 신규 나무를 일괄 재생성해 플레이어의 경작지·동선을 덮지 않고, 첫 단계에서는 테스트 영역 또는 미방문 청크에만 새 규칙을 적용한다.

보상 확정에는 자원 ID와 보상 순번을 사용해 중복 처리 여부를 기록한다. 드롭 스폰이 실패하면 보상을 대기 상태로 남기며 재생성·쿨타임만 진행시켜 아이템을 잃지 않게 한다. 바닥 아이템과 대기 보상도 저장 대상에 포함해야 한다. 현재 인벤토리·스킬·월드가 서로 다른 저장 슬롯을 사용하므로, 정상 저장·재접속 지원과 강제 종료 시점의 일관성 보장은 구분해서 검증한다. 강제 종료까지 보장하려면 공통 저장 스냅샷 또는 복구 기록이 추가로 필요하다.

## 구현 순서와 완료 기준

1. **벌목·흔들기:** 도끼 1~9단계 데이터, 참나무·단풍나무 테스트 배치, 타격 시점·SP·내구도, 씨앗 쿨타임, 원목·씨앗 드롭, 부분 HP·쿨타임·바닥 보상 저장을 구현한다. NPC 시스템 연결 전에는 개발용 해금 옵션을 제공한다.
2. **나무 순환:** 그루터기→성장→성목, 6종 데이터·외형, 지역별 80/20 배치, 도감·채집 경험치 연결을 완성한다. 에반 대화 시스템이 준비되면 정식 해금 조건을 연결한다.
3. **열매·약초:** 각각 대표 1종, 맨손 채집, 실제 사용처, 수확 후 재생성과 저장을 연결한다. 종류와 계절 분포는 데이터 확정 후 확장한다.
4. **발굴:** 기존 삽에서 흔적 우선 판정, 발굴 보상, 유물 도감, 위치 재선정과 상한을 구현한다.

첫 단계의 완료 판단은 나무를 클릭해 정해진 횟수만큼 베고 재료를 얻는 흐름과, 도끼 외 장비로 씨앗을 얻은 뒤 7일 동안 재지급되지 않는 흐름이 저장 후에도 유지되는지로 한다. 모든 확장 콘텐츠를 한 번에 만들어야 벌목을 검증할 수 있는 구조는 피한다.

검증할 주요 사례는 다음과 같다. 이 문서는 구성안이므로 아래 검증은 아직 실행하지 않았다.

- HP 60 나무의 도끼 단계별 타격 수와 SP 비용, SP·내구도 부족 시 상태 불변.
- 같은 동작의 타격 이벤트 중복 호출과 쓰러지는 나무 연속 클릭에서 보상·소모 중복 없음.
- 괭이·물뿌리개·낚싯대·삽을 들고 나무 클릭 시 흔들기만 수행.
- 흔들기 최초 보상, 336구간 직전 차단, 정확한 경계에서 지급, 쿨타임 중 무보상.
- 부분 피해·쿨타임·그루터기·성장·바닥 보상이 청크 이탈과 정상 저장 후 복원.
- 가방 부족·일부 수집·드롭 생성 실패에도 보상 유실 없음, 줍기로 경험치 중복 지급 없음.
- 일시정지·여러 날 시간 건너뛰기·성장 완료 시 플레이어와 충돌하는 상황 처리.
- 바이옴 수종 비율, 물·경작지·필수 경로 제외, 기존 저장에 나무 강제 생성 없음.

## 밸런스 확인 시 우선 볼 항목

최종 드롭 수량·성장 일수·도끼 내구도는 건축·제작의 재료 소모량과 함께 조정해야 한다. 초기 기준은 1단계 도끼의 나무 한 그루가 6타격·SP 60이라는 원본 수치에서 시작한다. 기존 대기 SP 회복은 초당 10이므로 벌목 도중 회복을 막고, 작업 사이 대기 회복을 포함한 실제 재료 수급 속도로 판단한다.

첫 플레이 확인에서는 나무 10그루를 벨 때 걸리는 시간, 탐사 한 번의 원목·씨앗 수량, 가방 점유, 다음 도끼 단계의 체감 차이를 기록한다. 희귀 부산물·스킬 트리·씨앗 식재·유물 판매가는 해당 아이템과 사용처가 확정된 뒤 추가한다.
