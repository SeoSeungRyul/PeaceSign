# 삽

새 게임은 단축바 5번 칸에 내구도 100의 삽을 지급합니다. `5`로 선택한 뒤 풀 또는 흙 칸을 우클릭하면 풀↔흙으로 전환됩니다. 성공한 전환만 내구도 1을 소모하며, 0이 되면 삽이 사라집니다. 흙·풀 아이템 보상은 없으므로 가방이 가득 차 있어도 사용할 수 있습니다.

물, 경작지, 바위나 작물이 있는 칸과 월드 밖은 변경하지 않습니다. 변경된 타일과 주변 8칸은 기존 자동 타일 규칙으로 다시 렌더링되며 청크 경계도 갱신됩니다. 타일과 삽 내구도는 기존 월드·인벤토리 저장 기능에 기록됩니다.

이전 인벤토리 저장은 5번 칸, 빈 단축바 칸, 빈 가방 칸 순서로 삽 하나를 지급합니다. 기존 아이템을 덮어쓰지 않습니다. 모든 슬롯이 차 있으면 지급을 보류하고 경고를 기록합니다.

`PeaceSign.Shovel.TerrainAndInventory` 자동화 테스트는 양방향 전환, 청크 경계 규칙, 저장 복원, 차단 대상, 내구도 소모·파괴, 가방 용량과 구버전 저장 마이그레이션을 검증합니다.
