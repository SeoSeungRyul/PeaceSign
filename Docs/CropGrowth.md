# 작물 수분과 일일 성장

2026-10-12 기획서의 물 주기 규칙을 적용했습니다. 물뿌리개를 Hotbar에서 선택하고 밭에 우클릭하면 수분이 true가 됩니다. 빈 밭에도 물을 줄 수 있고, 이미 젖은 밭에는 중복 적용하지 않습니다. 새 게임은 6번 칸에 물뿌리개를 지급합니다. 구버전 인벤토리는 6번, 다른 빈 Hotbar, 열린 빈 가방 순으로 보충하며 기존 아이템을 덮어쓰지 않습니다. 물 용량·보충·내구도는 이번 임시 물뿌리개에 포함하지 않습니다.

매일 오전 6시에 직전 하루의 수분을 먼저 판정하고 모든 밭을 마르게 합니다. 임시 작물은 젖은 날 한 단계 성장하며 파종 직후 1단계, 최대 5단계입니다. 마른 날에는 성장하지 않고 연속 두 번의 아침 판정에서 마른 상태면 작물을 제거합니다. 물을 주면 연속 건조 일수를 초기화합니다. 성숙 작물도 건조 피해를 받습니다. 06:00 직전 파종·물 주기는 바로 다음 아침 판정에 포함됩니다. 작물별 성장일과 성장률 20% 구간은 데이터 연결 작업에서 적용할 예정입니다.

시간 서브시스템의 갱신 이벤트로 지나간 오전 6시를 처리하며 개별 작물 타이머는 없습니다. `]`의 6시간 이동이나 여러 날 이동도 첫날 수분 판정과 이후 건조 판정을 반영합니다. 화면 밖 청크도 저장 데이터에서 처리하며 필요한 청크만 다시 그립니다. 밭은 Farm Set1~4 이미지를 자동 연결하며, 젖은 밭에는 Farm_Water를 밭보다 Z+1 높이에 겹칩니다. 마르면 물 이미지만 없어집니다. 작물은 기존 1~5개 구체 표시를 유지합니다.

월드 저장 버전 5는 수분, 연속 건조 일수, 마지막 아침 판정 번호를 저장합니다. 불러오기로 건조 기록이 초기화되거나 같은 아침이 중복 처리되지 않습니다. 게임을 꺼놓은 동안에는 성장하지 않습니다. 버전 4 이하의 작물은 기존 단계를 유지하고 첫날만 젖은 상태로 이관합니다.

5단계는 괭이로 수확해 가방에 작물을 지급하며 밭을 남깁니다. 맨손 제거와 건조 고사는 수확물·경험치를 주지 않습니다. 수확과 제거 후 밭의 수분은 그날 동안 유지됩니다. 새·벌레·보호시설과 거점 제한은 별도 작업입니다.
