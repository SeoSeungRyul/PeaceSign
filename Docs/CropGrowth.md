# 작물 성장과 수확

11월 9일 기획서 기준으로 상추 한 종을 연결했습니다. 시작 Hotbar 2번의 상추 씨앗은 임시 아이템 ID `Seed.Lettuce`를 사용합니다. 첫 밭 갈기가 성공하면 농사 레벨 1이 열립니다. 상추 씨앗을 들고 두 칸 안의 빈 밭에 우클릭하면, 봄이고 농사 레벨이 1 이상일 때 씨앗 한 개를 사용합니다. 젖은 밭과 마른 밭 모두 파종할 수 있습니다.

`DT_Crop`의 상추 행은 작물 ID `010101`, 봄, 유효 성장 시간 3일, 요구 레벨 1, 추가 수확 0%, 판매가 50을 사용합니다. 판매 거래와 아이콘은 이 작업에 포함하지 않습니다. `SourceData/CropTables/Crop.csv`는 테이블에 가져올 수 있도록 정리한 상추 데이터입니다. 이미 심은 테스트 작물은 기존 ID를 유지하며 유효 성장 시간 4일을 사용합니다.

게임 시간 10분 경계마다 젖은 구간만 성장 시간에 더합니다. 구간 중간에 물을 주거나 심으면 해당 시각부터 계산합니다. 0~20% 미만은 1단계, 20~40% 미만은 2단계, 40~60% 미만은 3단계, 60~100% 미만은 4단계, 100%는 수확 가능한 5단계입니다. 시계 UI는 기존 30분 단위를 유지합니다.

오전 6시에는 직전까지의 성장을 먼저 반영한 다음 미급수와 계절을 판정하고 밭을 마르게 합니다. 첫 06:00은 미급수 횟수에 포함하지 않으며, 이후 연속 두 번 미급수면 작물만 제거됩니다. 물을 주면 미급수 일수가 초기화됩니다. 다 자란 작물은 미급수 판정에서 제외되지만, 재배 계절이 끝나면 제거됩니다. 시간 건너뛰기는 지난 06:00 경계를 반영하고 오프라인 시간은 반영하지 않습니다.

두 칸 이내의 다 자란 작물은 F를 0.8초 누르면 수확할 수 있습니다. 마우스가 가리키는 수확 가능 작물이 있으면 우선 선택하고, 없으면 가까운 성숙 작물을 고릅니다. 작물 수확은 덤불 채집보다 우선하며, F를 놓거나 움직이거나 피격되거나 대상이 바뀌면 취소합니다. 완료 시 작물만 제거하고 밭과 현재 수분은 유지합니다. 보상은 가방에 먼저 들어가며 초과분은 저장되는 바닥 드롭으로 남습니다. 괭이는 밭 갈기에만 사용합니다.

월드 저장 버전 9는 파종 시각, 누적 성장 시간, 마지막 성장 처리 시각을 보존합니다. 기존 30분 단위 자동 저장은 성장 갱신을 반영한 뒤 실행합니다. 이전 작물은 기존 성장 단계를 해당 단계의 최소 진행률로 이관합니다. 인벤토리 저장 버전 10은 기존 임시 씨앗을 수량과 자리를 유지한 채 상추 씨앗으로 연결합니다.
