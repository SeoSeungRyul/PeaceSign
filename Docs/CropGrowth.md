# 임시 작물 성장

파종 직후 1단계이며, 게임 1일(30분 갱신 48회, 기본 속도에서 현실 24분)마다 한 단계씩 올라 최대 5단계가 됩니다. 파종 구간 시작으로부터 4일(현실 96분)이면 5단계입니다. 임시 외형은 단계와 같은 수의 갈색 구체이며, 중앙과 네 모서리에 최대 5개를 배치합니다.

파종은 시각을 30분 단위로 내림하여 기록합니다. 1일차 06:00~06:29에 심은 작물은 2~5일차 06:00에 성장합니다. 1일차 06:30~06:59에 심은 작물은 2~5일차 06:30에 성장합니다. 구간 후반에 심으면 실제 파종 순간부터 첫 성장까지 24시간보다 최대 29분 짧을 수 있습니다.

월드 시간 서브시스템은 날짜를 포함한 누적 30분 번호와 갱신 이벤트만 제공합니다. 그리드가 이벤트를 구독해 파종 번호별 묶음을 갱신하며 개별 작물 타이머는 만들지 않습니다. 성숙한 작물은 묶음에서 제외하고 화면에 보이지 않는 청크도 데이터는 성장합니다. 바뀐 청크만 이벤트당 한 번 다시 그리고 저장도 이벤트당 한 번 수행합니다.

저장에는 단계, 파종 번호와 저장 시점의 시간 번호가 포함됩니다. 저장된 게임 시간도 함께 복원되며 게임을 꺼놓은 동안은 성장하지 않습니다. 이전 시간 단위로 저장된 작물은 현재 단계보다 낮아지지 않고, 시간 기록이 없는 이전 저장의 씨앗은 불러온 시점을 기준으로 1단계부터 자랍니다.

5단계 작물은 괭이로 우클릭하면 수확되고 밭은 빈 `TilledSoil` 상태로 남습니다. 맨손 우클릭은 성장 단계와 관계없이 작물을 제거하며 수확물은 주지 않습니다. 현재 수확 수량은 인벤토리 구현 전까지 플레이 세션 동안만 유지되는 임시 카운터로 상태창에 표시합니다. 환경 조건과 물 주기는 포함하지 않습니다.
