# 기존 월드의 두 번째 물 방식

GridWorld의 **Use Native Water** 기본값은 켜짐이다. 새 월드뿐 아니라 기존 세이브의
물 칸도 렌더링할 때 Water Body Custom + Water Waves 방식으로 표시한다.
맵 에셋/지형 데이터/세이브 버전은 변경하지 않아 월드를 초기화할 필요가 없다.

## 에디터 설정

- GridWorld → Grid World / Water → **Use Native Water**: 새 물/기존 머티리얼 전환.
- **Refresh Water Rendering**: 현재 청크 또는 에디터 프리뷰를 다시 그린다. 세이브를 쓰지 않는다.
- **Supply Native Water Reflections**: 두 번째 물과 같은 낮 하늘 반사를 실행 중에 제공한다.
  기존 SkyLight가 있으면 강도·색은 유지하고 반사 큐브만 임시 교체하며, 끄면 원래 설정으로 복귀한다.
  SkyLight가 없으면 GridWorld 소유의 임시 조명을 사용한다. 에디터 맵의 조명 설정은 덮어쓰지 않는다.
- 파도: `/Game/Art/Tiles/Water/LinkPrototype/WW_LinkWater`
- 색·반사·노멀: `/Game/Art/Tiles/Water/LinkPrototype/MI_LinkWater`
- 기존 효과: `/Game/Art/Tiles/Water/MI_WaterSurface` (아래→위 흐름 포함, 그대로 보존).

파도 높이 에셋을 수정한 뒤에는 Refresh Water Rendering을 누르거나 플레이를 재시작한다.
실행 중 에셋만 바꾸고 청크를 갱신하지 않으면 물 깊이는 이전 값일 수 있다.

## 렌더링과 수명

물이 있는 청크마다 네이티브 물 액터를 하나만 소유한다. 재빌드는 재사용하고,
물이 없어지거나 기존 방식으로 바꾸거나 청크를 내리면 해당 액터를 제거한다.
서로 이웃한 청크의 표면 영역은 중복되지 않으며 동일한 파도 에셋과 월드 좌표 위상을 쓴다.
원본 타일 그림은 별도 해안 컷아웃 머티리얼로 유지한다.
TestMap의 엔진 기본 격자 바닥은 새 물보다 위에 있어 물을 가린다. 정확히 해당 엔진 템플릿
메시/격자 머티리얼 조합만 렌더링에서 임시로 숨기며, 충돌은 유지하고 기존 방식 복귀 시 다시 보인다.
바닥 액터나 맵 에셋을 삭제하지 않는다. 사용자 제작 바닥/다른 메시에는 이 처리를 적용하지 않는다.
물 표면은 육지보다 max(20cm, 합산 최대 파고+2cm) 낮게 두어 파도가 풀을 덮지 않게 한다.
월드 바깥 빈 칸으로 표면이 나가지 않도록 유효 지형 영역으로 제한한다.

기존 그리드의 물 충돌/낚시 가능 칸/물고기 지역 판정은 그대로다.
추가 물 액터의 충돌·내비게이션은 끈다. 낚시 찌의 표시 위치만 실제 물 높이 계산을 따라간다.
기존 해안 그림에 포함된 녹색 가장자리와 물-흙 전용 접합 아트 문제는 별개이며 변경하지 않는다.
색상 기반 컷아웃이어서 원본의 일부 얇은 물 무늬가 남을 수 있다.

## 검증 방법

`PeaceSign.Grid.NativeWorldWater`: 물 액터 생성/재사용/제거, 기존 방식 복귀,
부분 월드 경계, 지형 불변, 찌 높이와 기본 설정 검사.
`PS.Water.WorldSmoke`: TestMap에서 물가를 찾아 실제 게임 백버퍼를 비교하는 개발용 검사.
반드시 별도 UserDir을 사용해야 한다. 테스트가 플레이어 위치를 옮기고 완료 후 프로세스를 종료한다.

2026-11-06 검증: Development Editor 빌드 성공. Grid/Farming/Fishing/Mining/Shovel
자동화 22개 전부 통과. 별도 UserDir로 기존 TestMap을 실행한 실제 게임 뷰포트 검사도 통과했다.
네이티브 물 액터 16개를 확인했고, 고정 카메라의 수면 영역 5,041픽셀 중 453픽셀이
파도 시간 변경에 따라 바뀌었다. 패키징된 게임 빌드는 이번 검증 범위에 포함하지 않았다.
