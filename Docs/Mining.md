# 임시 채굴

절차 생성된 돌 타일은 내구도 3으로 시작합니다. 플레이어는 육지에서 직선 두 칸 또는 대각선 한 칸 안의 돌을 우클릭해 한 번에 피해 1을 줍니다. 남은 내구도는 월드 저장 데이터에 기록되며 청크가 언로드되거나 게임을 다시 시작해도 유지됩니다.

세 번째 유효 타격에서 돌 타일은 흙 타일로 바뀌고 돌 아이템 한 개가 인벤토리에 즉시 들어갑니다. 가방이 가득 찬 경우에만 해당 셀 위에 월드 아이템으로 생성됩니다. 이미 파괴된 셀은 다시 채굴할 수 없으므로 아이템도 중복 생성되지 않습니다. 기존 저장에 내구도 정보가 없는 돌 타일은 불러올 때 내구도 3으로 보정합니다.

파괴 상태와 남은 내구도는 월드 저장에 유지됩니다. 개발용 `R` 초기화는 저장을 삭제하고 현재 보이는 청크 렌더러를 즉시 절차 생성 상태로 다시 구성하므로 흙으로 변한 자리에 원래 돌이 돌아옵니다.

현재 임시 돌 곡괭이가 새 게임 Hotbar 4번 칸에 지급되며 선택하면 곡괭이 장비로 표시됩니다. 다만 채굴 피해는 아직 모든 장비가 동일하게 1이며 곡괭이 내구도도 소모하지 않습니다. 장비 공격력 차이, 광물, 채광 경험치, 광맥과 리젠은 포함하지 않습니다.

`PeaceSign.Mining.DamageDestroyAndDrop` 자동화 테스트는 채굴 거리, 세 번의 타격, 돌 한 개 드롭, 중복 방지와 저장 복원을 검증합니다.
