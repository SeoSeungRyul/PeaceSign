# 임시 채굴

절차 생성된 돌 타일은 기획서 기준 HP 30으로 시작합니다. 플레이어는 육지에서 직선 두 칸 또는 대각선 한 칸 안의 돌을 우클릭하고 현재 장비의 채굴력만큼 피해를 줍니다. 맨손, 곡괭이 이외 장비와 돌 곡괭이의 채굴력은 10이므로 기본 돌은 세 번에 파괴됩니다. 남은 HP는 월드 저장 데이터에 기록되며 청크가 언로드되거나 게임을 다시 시작해도 유지됩니다.

세 번째 유효 타격에서 돌 타일은 흙 타일로 바뀌고 돌 아이템 한 개가 인벤토리에 즉시 들어갑니다. 가방이 가득 찬 경우에만 해당 셀 위에 월드 아이템으로 생성됩니다. 이미 파괴된 셀은 다시 채굴할 수 없으므로 아이템도 중복 생성되지 않습니다. 기존 저장의 돌 HP 1~3은 불러올 때 10~30 기준으로 변환한 뒤 좌표 기반 광물을 배정하며, 이미 받은 피해량은 광물의 새 최대 HP에서도 유지합니다.

파괴 상태와 남은 내구도는 월드 저장에 유지됩니다. 개발용 `R` 초기화는 저장을 삭제하고 현재 보이는 청크 렌더러를 즉시 절차 생성 상태로 다시 구성하므로 흙으로 변한 자리에 원래 돌이 돌아옵니다.

현재 임시 돌 곡괭이가 새 게임 Hotbar 4번 칸에 지급되며 선택하면 곡괭이 장비로 표시됩니다. 기획서의 곡괭이별 채굴력(돌 10, 구리 15, 철 25, 은 40, 금 65, 티타늄 105, 루미석 170, 아스테륨 275)은 아이템 데이터로 정의되어 있습니다. 아직 기본 지급은 돌 곡괭이뿐이며 곡괭이 내구도 소모, 채광 경험치, 광맥 단위 생성과 리젠은 포함하지 않습니다.

돌 블록에는 선택적으로 구리, 철, 은, 금, 티타늄, 루미석 또는 아스테륨 광물이 포함됩니다. 총 HP는 기본 30에 광물별 추가 HP를 더한 45, 75, 120, 195, 315, 510, 825이며 광물마다 별도 색상의 타일 인스턴스로 표시됩니다. 곡괭이로 파괴하면 돌과 해당 광석이 함께 인벤토리에 들어가고 공간이 없으면 월드 아이템으로 떨어집니다. 맨손이나 다른 장비로 파괴하면 돌만 획득합니다.

돌과 광물이 든 돌 타일은 플레이어의 이동을 막습니다. 연속된 차단 타일은 청크의 행 단위 박스 충돌로 합쳐서 처리하며, 채굴로 돌이 흙이 되는 즉시 해당 위치의 충돌이 제거됩니다. 저장 월드를 다시 불러와도 타일 상태에 맞춰 충돌이 구성되고, 개발용 `R` 초기화로 돌이 복원되면 이동 차단도 함께 복원됩니다. 물 타일도 같은 충돌 구성에서 계속 플레이어를 막습니다.

월드는 거점으로부터의 거리를 8개 구간으로 나눕니다. 광물별 최소 등장 구간과 가중치는 Grid World의 `MineralSpawnRules`에서 조정할 수 있으며, 먼 구간으로 갈수록 상위 광물이 후보에 추가됩니다. 생성된 광물 종류, 남은 HP와 파괴 상태는 월드 저장에 유지됩니다.

`PeaceSign.Mining.DamageDestroyAndDrop` 자동화 테스트는 채굴 거리, 장비별 채굴력, 세 번의 타격, 돌 한 개 보상, 중복 방지, 저장 복원, 구버전 저장 마이그레이션과 채굴 전·후·초기화 후의 이동 차단 상태를 검증합니다.
