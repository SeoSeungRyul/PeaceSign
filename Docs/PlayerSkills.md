# 플레이어 분야별 스킬

`UPSPlayerSkillComponent`는 낚시, 농사, 채광, 전투의 레벨, 경험치, 미사용 포인트와 배운 스킬 랭크를 관리합니다. 각 분야는 레벨 0에서 시작하고 경험치 100마다 레벨이 1 오르며 해당 분야 포인트를 1 얻습니다. 남은 경험치는 다음 레벨로 이월되고 최대 레벨은 20입니다.

현재 낚시 성공과 작물 수확 성공이 각각 해당 분야 경험치 2를 줍니다. 낚시 실패·취소와 수확 실패는 경험치를 주지 않습니다. `LearnSkill`은 최대 랭크, 포인트 비용과 선행 스킬 랭크를 검사합니다. 구체적인 스킬 효과 수치가 기획서에 확정되지 않아 효과 적용은 데이터가 정해진 뒤 연결할 수 있도록 상태와 API만 마련했습니다.

진행 상태는 `PeaceSignSkills` 저장 슬롯에 자동 저장됩니다. 초기화 기능은 개발용 API이며 플레이 중 되돌리기 UI는 제공하지 않습니다.

`PeaceSign.Skills.ProgressionAndSave` 자동화 테스트는 경험치 이월, 레벨 포인트, 선행 조건, 학습 랭크와 저장 복원을 검증합니다.
