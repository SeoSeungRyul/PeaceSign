## 플레이 확인

- 새 게임의 단축바 9번에 내구도 100의 1단계 도끼를 지급한다. 기존 인벤토리는 9번, 다른 빈 단축바, 열린 빈 가방 순으로 지급한다. 공간이 없으면 지급을 보류하고 빈칸이 생겼을 때 보충한다.
- 테스트 나무는 그리드 기준 X=-20~-5, Y=6~21 영역에 생성한다. 서쪽은 참나무 중심, 동쪽은 단풍나무 중심이며 80%/20%로 수종을 선택한다. 물·돌·작물·경작지·타일 스탬프·거점 보호 영역과 필수 경로에는 생성하지 않는다.
- 도끼로 나무를 우클릭하면 0.6초간 작업한다. 0.3초 시점에 피해·SP·내구도를 한 번 적용한다. 기본 나무 HP는 60이며 1단계는 6회 타격한다.
- 맨손이나 도끼·나무 씨앗 외 장비로 나무를 우클릭하면 0.8초간 흔든다. 최초 시도와 마지막 유효 추첨부터 게임 7일 경과 시 다시 추첨한다. 흔들기는 SP·장비 내구도를 소모하지 않는다. 꽝도 유효 추첨으로 처리한다.
- 연결한 CSV 기준 벌목은 원목 3~6개 중 하나와 씨앗 0~2개 중 하나를 각각 추첨한다. 흔들기는 씨앗 1개 40%, 사과 1~5개 각각 3.2%, 밤 1개 24%, 꽝 20% 중 하나를 선택한다. 벌목의 보상 기록은 마지막 타격에 확정하고 화면의 드롭은 쓰러짐 연출이 끝난 뒤 나타난다.
- 원목과 씨앗은 쓰러짐이 끝난 뒤 인벤토리와 같은 아이콘으로 짧게 튀어 올라 착지한다. 같은 아이템은 한 묶음으로 보인다. 물에서 자란 나무의 보상은 작업자가 서 있던 육지에 떨어진다.
- 착지한 바닥 아이템과 같은 타일에 플레이어가 들어오면 줍는다. 인접 타일에서는 줍지 않는다. 가방이 차면 바닥에 남고, 같은 타일에서 공간을 확보하면 다시 수집을 시도한다. 한 보상 스택을 전부 넣을 공간이 있을 때 수집한다.
- 나무 씨앗 6종을 퀵슬롯에 옮기고 가까운 빈 풀·물 타일을 우클릭하면 씨앗 1개가 묘목으로 바뀐다. 초록 테두리는 심을 수 있는 칸, 빨간 테두리는 심을 수 없는 칸이다. 물 타일은 육지에서 접근할 수 있는 칸에 심으며 이동 제한은 유지된다.
- 묘목은 게임 시계 기준 48시간 뒤 같은 수종의 성목이 된다. 묘목은 그 칸을 점유하며 성목이 된 뒤부터 흔들거나 벨 수 있다.
- 이동·장비 교체는 작업 중 제한한다. 책을 열거나 포커스를 잃으면 진행 중 작업을 취소한다. 타격 전 취소는 무소모, 타격 후 취소는 이미 적용된 결과를 유지한다.

이동 범위는 직선 두 칸·대각선 한 칸이다. 물·오브젝트·물리 벽 너머의 작업은 막는다. 나무의 수관이 아닌 줄기 셀에 커서를 두어야 한다. 나무를 클릭한 입력은 기존 농사·낚시·삽 동작으로 넘기지 않는다.

## 저장과 호환

월드 저장 버전 7은 나무 좌표·수종·남은 HP·흔들기 가능 시각·보상 순번, 묘목의 성장 완료 시각과 미수집 드롭을 기록한다. 베어낸 테스트 배치 ID는 따로 저장한다. 기존 저장의 그루터기는 칸을 비우고 배치 ID와 미수집 보상은 보존한다. 청크에서 멀어져 표현 액터가 사라져도 저장 상태는 유지한다.

기존 저장에는 명시한 개발용 테스트 구역에만 나무를 보충하며, 실제 저장된 땅과 오브젝트의 점유 상태를 확인한다. 최초 배치가 완료된 저장은 다시 실행해도 나무를 재생성하지 않는다. 개발용 R 초기화는 나무·미수집 채집 드롭도 초기화하므로 플레이 저장 검증에는 사용하지 않는다.

정상 저장·재접속을 지원한다. 기존 인벤토리와 월드는 서로 다른 파일에 저장되므로 두 파일 쓰기 사이 강제 종료까지 원자적으로 보장하지는 않는다. 이를 보장하려면 공통 스냅샷 또는 복구 기록을 추가해야 한다.
