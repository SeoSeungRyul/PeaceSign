# 원본 세트 테스트 보드와 도장

## 테스트 보드 (플레이 불필요)

1. 빌드 후 언리얼을 다시 연다.
2. 콘텐츠 브라우저에서 C++ Classes → PeaceSign → World → PSTileSetBoard를 레벨에 끌어놓는다.
   액터 배치 패널에서는 PS Tile Set Board로 검색할 수 있다.
3. 위쪽은 Dirt, 아래쪽은 Water다. 각 가족 안에서 왼쪽부터 Set1, Set2, Set3,
   다음 줄 Set4, Set5, Set6 H, 그다음 줄 Set6 V, Set7, Set8, 마지막 줄 Set9, Set10, Set11 순서다.
   Dirt와 Water 모두 Set1~11을 표시한다.
4. Board Cell Size로 크기를 조정하고 Refresh Tile Set Board로 다시 표시한다.

모든 원본 조각을 정확히 한 번씩 표시하며 자동 연결을 적용하지 않는다.
보드는 월드 생성/저장에 영향을 주지 않고, 충돌이 없으며 에디터 전용이다.
Water Set2는 번호 없는 파일을 사용한다.
물 그림자의 원본 위쪽이 고정 탑다운 카메라의 화면 위쪽(+X)을 향하도록
물 아트만 +90도 회전한다. 연결 마스크와 도장 조각 순서도 보정하므로
물 경계와 도장 영역은 유지된다. 흙 아트 방향은 변경하지 않는다.

## GridWorld에 세트 도장 배치

1. 레벨의 GridWorld 액터를 선택한다.
2. Grid World → Tile Stamps → Selected Tile Stamp를 펼친다.
3. Origin은 월드 좌표가 아닌 칸 좌표다. 이미지의 왼쪽 위 조각이 놓이는 칸을 입력한다.
   이미지의 오른쪽은 월드 +X, 아래쪽은 월드 +Y다.
4. Set을 1~11로 고른다. 물이면 Water를 체크한다.
   Set6의 세로 길은 Vertical을 체크한다.
5. Add Tile Stamp를 누른다. Tile Stamps 목록에 추가되고 그리드 프리뷰가 갱신된다.
6. 레벨을 저장하면 도장 목록이 레벨에 저장된다.

Set1~5는 3×3칸, Set6 H는 3×1칸, V는 1×3칸이다.
흙과 물 Set7~9는 2×2칸이며 LT, RT / LB, RB 순으로 배치한다.
Set10은 2×1칸으로 L / R 순서다. Set11은 3×3 영역의 십자 배치다:
위 (1,0)에 T, 왼쪽 (0,1)에 L, 오른쪽 (2,1)에 R, 아래 (1,2)에 B를 놓는다.
Set11의 가운데와 네 구석은 도장을 찍지 않아 기존/생성 지형을 유지한다.
테스트 보드에서는 이 빈 위치에 아무것도 표시하지 않는다.
도장은 월드 안에 완전히 들어가야 한다. 겹치면 목록의 뒤에 있는 도장이 우선한다.
삭제/수정은 Tile Stamps 배열에서 한 뒤 Generate Grid Preview를 누른다.
도장 위에는 절차 생성 돌이나 광석을 올리지 않는다.

도장 칸은 원본 Variant와 Dirt/Water 아트 종류를 고정한다.
따라서 풀 중심 조각도 작은 풀 섬/풀 구멍을 그대로 표시한다.
이 고정은 저장/로드와 청크 경계에서 유지된다.
삽/경작 등으로 지형 종류를 바꾸면 해당 칸의 고정은 해제되고 자동 연결을 쓴다.
주변 칸을 바꿔도 나머지 도장 조각은 그대로라, 도장 바깥 경계까지 자동으로 맞추지는 않는다.

## 기존 세이브

Add Tile Stamp는 세이브 파일을 덮어쓰거나 삭제하지 않는다.
플레이에서 기존 저장 청크가 있으면 그 상태가 새 도장보다 우선한다.
프리뷰와 플레이가 다르면 테스트용 Save Slot Name을 별도로 지정해서 확인한다.
테스트 후 원래 슬롯 이름으로 돌리면 기존 월드를 다시 사용할 수 있다.
기존 플레이 데이터를 초기화할 필요는 없다.

## 범위

이 기능은 원본 세트를 그대로 확인/배치하기 위한 것이다.
흙 자동 연결은 Set7/8의 직선+안쪽 모서리 조합 8개와 Set9의 안쪽 모서리 3개 조합 4개를 지원한다.
새 흙 Set9 Variant는 60~63으로 추가하여 기존 1~59의 저장 번호를 유지한다.
흙과 물 Set10은 서로 마주 보는 안쪽 풀 모서리 두 개 조합 (351, 431)을 지원한다.
Set11은 직선 경계와 안쪽 풀 모서리 두 개 조합 (267, 269, 263, 270)을 지원한다.
Set11은 Set5의 일부 조각과 마스크가 같지만 경계 곡선이 달라 자동 연결에서 Set11을 우선한다.
새 Variant는 Set10 L/R = 64/65, Set11 T/L/R/B = 66/67/68/69이며 기존 1~63은 바꾸지 않는다.
물 자동 연결도 Set7/8의 8개 조합과 Set9의 안쪽 모서리 3개 조합 4개를 지원한다.
새 물 Variant는 52~63으로 추가하여 기존 1~51의 저장 번호를 유지한다.
물 Set7/8 도장은 아트 회전에 따라 서로의 조각을 사용하며, Set9~11은 같은 세트 안에서 순서를 보정한다.
물과 흙의 전용 접합 아트는 아직 적용하지 않는다. 그 외 미지원 조합은 기존 대체 규칙을 유지한다.
아직 없는 나머지 복합 조합의 4분할 렌더링은 별도 작업이다.
충돌/농사 판정은 이미지의 모든 픽셀이 아니라 칸 중심의 지형 종류를 기준으로 한다.
