# 풀 타일 덤불

2026-11-05. TestMap의 고정 20×20칸 구역에서 유효한 풀 타일에 최대 8개의 덤불을 배치한다. 돌·물·작물·나무·스탬프와 보호 구역을 피한다. 그림은 투명 PNG 원본의 비율을 유지하며 한 타일 안에 들어간다. 이동 충돌은 없다.

F키는 2칸 안에서 가까운 덤불을 선택하고, 같은 거리이면 바라보는 방향을 우선한다. 우클릭은 커서의 덤불을 선택한다. 두 입력 모두 0.8초 누르면 한 번 채집한다. 키 해제·이동·피격·메뉴·대상 변경 시 진행을 취소한다. 진행 중인 덤불은 고정한다.

기획서의 초원 보상인 봄·여름 야생딸기와 가을·겨울 블랙베리를 사용한다. 정식 데이터 ID가 없어 `Forage.WildStrawberry`, `Forage.Blackberry`를 임시로 사용한다. 열매별 전용 아이콘은 제작 전이며 기존 아이템 표시 방식으로 이름을 표시한다.

채집마다 1~3개를 동일 확률로 지급한다. 가방의 기존 스택과 빈칸에 들어갈 만큼 먼저 넣고 초과분은 같은 위치에 드롭한다. 실제로 가방에 들어간 아이템만 채집 도감에 등록한다.

덤불은 총 3회 채집한다. 첫 두 번은 게임 시간 2일 후 같은 열매가 다시 열린다. 세 번째에는 제거하고 3일 뒤 같은 구역의 유효한 빈 풀 타일에 보충한다. 보충 위치는 게임 시간 1시간마다 확인한다. 새 덤불은 생성 시점 계절로 열매를 선택한다.

위치·열매 종류·남은 횟수·쿨타임·보충 대기와 도감 발견을 저장한다. 재접속이나 지역 이동으로 개체 수와 횟수를 초기화하지 않는다. 아트 교체는 GridWorld의 Bushes > Texture에서 할 수 있다.

`Scripts/ImportBushPrototype.py`는 임시 텍스처를 가져오고 TestMap의 구역을 활성화한다. `PeaceSign.Gathering.BushHoldRewardsAndSave`는 양쪽 입력, 조기 해제·이동 취소, 부분 수납·초과 드롭, 횟수·리스폰·저장을 확인한다. `PS.Bush.Smoke`는 별도 `-UserDir`의 실제 TestMap에서 그림과 채집을 확인한다.
