# 게임 시간

게임 월드마다 오전 6시에 시작합니다. 플레이 중 현실 30초마다 게임 시간 30분이 진행됩니다. 현실 1분이 게임 1시간이며, 현실 24분(1,440초)이 게임 24시간입니다. 시간을 건너뛰지 않고 날짜는 자정에 바뀝니다. 화면에는 오전/오후와 시간을 표시합니다.

`UPSGameTimeSubsystem`이 시간 상태를 소유하고 변경 이벤트를 보냅니다. `UPSGameTimeWidget`은 오른쪽 위에 고정되며 이 이벤트에서만 시간을 갱신합니다. UI를 다시 생성하거나 플레이어 폰이 바뀌어도 월드의 시간은 유지됩니다. 게임 일시정지 중에는 시간이 멈추며 시간 배율의 영향을 받습니다.

개발 중 성장 확인을 위해 `]` 키를 누르면 게임 시간이 6시간 진행됩니다. 시간 UI, 작물 성장과 저장도 변경된 시각을 즉시 반영합니다.

저장 데이터가 없는 새 월드나 새 PIE 실행은 오전 6시에 시작합니다. 월드를 저장할 때 날짜, 현재 30분 구간과 구간 안에서 흐른 실제 시간도 함께 저장하므로 다시 실행하면 같은 시점부터 이어집니다. 농사는 시간 갱신 이벤트와 누적 30분 번호를 이용하며, 시간 서브시스템 자체는 작물 규칙을 알지 못합니다. 작물의 저장·복원은 `CropGrowth.md`에 설명합니다. 수면 연출과 인벤토리 메뉴의 일시정지는 아직 연결하지 않았습니다.

`PeaceSign.Time.Clock` 테스트는 30초 경계, 정오·자정, 새벽 시간의 연속 진행, 1,440초 하루 주기, 긴 프레임과 누적 잔여 시간을 검증합니다.
