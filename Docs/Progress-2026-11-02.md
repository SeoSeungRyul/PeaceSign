# 2026년 11월 2일 작업 정리

## 오늘 반영한 내용

- 11월 2일 데이터 시트의 Item, TreeCutDrop, TreeShakeDrop을 Unreal CSV와 DataTable로 연결했다. Item 66행, 벌목 42행, 흔들기 48행이며 한국어와 아이템 ID의 앞자리 0을 보존한다.
- 벌목은 원목과 씨앗의 수량을 각각 추첨하고, 흔들기는 씨앗·사과·밤·꽝 중 하나를 추첨한다. 저장된 보상은 불러올 때 다시 추첨하지 않는다.
- 기존 수종 테이블은 참조와 실제 값을 점검한 뒤 제거했다. 새 나무의 HP는 Gathering 컴포넌트의 Tree Max Health에서 설정하고, 저장된 나무의 남은 HP는 보존한다. 수종별 드롭 그룹과 도끼 데이터는 유지한다.
- 원목 6종과 씨앗 6종을 각각 256×256 투명 PNG로 분리하고 비율·가운데 정렬·여백을 맞췄다. 원본과 개별 PNG 및 ZIP은 SourceArt/Gathering에 있다.
- PNG를 UI 텍스처로 가져와 `DT_Item.IconID → DT_GatheringIcon → Texture2D`로 연결했다. 바닥에서 주운 아이템은 수종별 ID와 수량을 보존해 가방에 들어가며, 단축바에서도 같은 그림을 표시한다.
- 가방이 가득 차면 보상을 바닥에 보존하고 공간을 만든 뒤 수집한다. 저장·불러오기와 예전 Log.Oak 등의 ID 호환을 확인했다.
- 엑셀에서 CSV를 다시 추출해도 원목·씨앗 12종의 개별 아이콘 ID를 유지하도록 추출 스크립트를 보완했다.

## 이번 PR에 함께 포함하는 누적 작업

사용자 요청에 따라 10월부터 아직 커밋하지 않은 프로젝트 변경 전체를 함께 포함한다. 농사 도구와 강화 괭이, 밭·물 자동 연결, 낚시 투척·회수·결과 표시와 도감, 책 형태의 인벤토리·도감 UI, 공용 글꼴, 나무 채집 기반 구현 및 관련 에셋·스크립트·문서를 포함한다. 임시 로그, 테스트 저장 파일과 빌드 캐시는 제외한다.

## 검증

- UE 5.8 `PeaceSignEditor Win64 Development` 빌드 성공.
- 실제 렌더링 환경에서 전체 `PeaceSign.` 자동화 테스트 29개 성공.
- 새 `PeaceSign.Gathering.InventoryIconsAndPickup`은 6수종의 흔들기·벌목·수집, 아이콘 12종, 단축바 이동, 저장 복원, 가방 공간 부족과 기존 ID 호환을 확인한다.
- 실제 WBP를 1280×800과 1920×1080으로 렌더링해 그림과 투명 배경을 확인했다. 에디터 검증에서는 위젯 생성으로 로드되는 텍스처의 비동기 컴파일을 마친 뒤 촬영한다.
- 최종 캡처는 [인벤토리 검증 화면](Images/GatheringInventory-20261102.png)이다. 테스트용 수량과 배치는 실제 사용자 저장에 넣지 않았다.
