# 기본 농사 도구 조작

2026-10-19 기획서의 기본 괭이·물뿌리개 조작을 적용했습니다.

- Hotbar에서 괭이 또는 물뿌리개를 선택하고 우클릭하면 캐릭터가 바라보는 바로 앞 1칸에 사용합니다. 마우스 위치는 사용하지 않습니다. 대각선 이동 뒤 방향은 캐릭터 이미지와 같은 상하 방향으로 결정합니다.
- 사용 가능한 칸은 초록 테두리, 사용할 수 없는 칸은 빨강 테두리로 표시합니다. 밭의 수분 이미지보다 위인 Z+4에 충돌 없는 테두리 메시를 표시합니다.
- 기본 사용 시간은 현실 시간 0.5초입니다. 시작 시 조건을 검사하고, 완료 시 다시 검사한 뒤 효과를 한 번 적용합니다. 반복 클릭으로 타이머를 재시작하지 않습니다.
- 사용 중 이동·달리기·구르기·Hotbar 선택·Hotbar 드래그와 아이템 이동·인벤토리 및 관련 메뉴 열기를 막습니다. 행동 중에는 SP 자연 회복을 멈춥니다. 별도 SP 소모량은 추가하지 않았습니다.
- 죽음, 캐릭터 교체, 강제 위치 이동으로 앞칸 변경, 외부 시스템의 장비 제거·교체는 진행 중 효과를 취소하고 이동 잠금을 해제합니다. 일시정지 중에는 남은 시간이 줄지 않습니다.
- 괭이는 작물이 없고 장애물이 없는 풀·흙만 밭으로 바꿉니다. 기존 임시 기능인 성숙 작물 수확은 예외로 유지하며 가방 공간과 도구 내구도도 확인합니다. 어린 작물이나 돌에는 사용할 수 없습니다.
- 물뿌리개는 장애물이 없는 마른 밭에 사용합니다. 빈 밭과 작물이 있는 밭 모두 가능하며 이미 젖은 밭에는 사용할 수 없습니다. 수분·일일 성장 규칙은 기존대로 유지합니다.

`APSPlayerController`의 `FarmActionDuration` 기본값은 0.5초입니다. `OnFarmToolStarted`와 `OnFarmToolFinished` Blueprint 이벤트는 애니메이션·소리를 연결할 수 있는 지점입니다. 이번 변경에서는 전용 애니메이션이나 소리 에셋을 추가하지 않았습니다.

씨앗 파종과 맨손 제거는 기존 커서 조작을 유지합니다. 거점·건물 제한과 데이터 테이블 확장은 다음 작업입니다.

## 1차 강화 괭이의 충전 사용

`Hoe.Upgrade1`은 괭이 아이템의 변형으로 저장합니다. 새 게임의 Hotbar 7번 칸에 임시 지급합니다. 버전 6 이하 저장은 기존 지급 여부를 확인한 뒤 7번, 다른 빈 Hotbar, 열린 가방의 빈 칸 순서로 한 개를 보충하며 기존 아이템은 덮어쓰지 않습니다. 모든 칸이 가득 차면 지급 대기를 저장하고 이후 아이템 변경으로 빈 칸이 생길 때 한 번 지급합니다. 저장 버전 7부터 ID와 내구도, 지급 대기를 유지하고 중복 지급하지 않습니다. 강화 재료·비용과 실제 강화 기능은 포함하지 않았습니다.

강화 괭이의 우클릭 누름은 충전을 시작합니다. 0.5초 미만에 떼면 앞 1칸, 0.5초 이상 누르고 떼면 앞칸과 그 좌우의 가로 3칸에 사용합니다. 충전 완료만으로는 효과가 발생하지 않습니다. 충전 시간과 사용 동작 시간은 별개이며, 버튼을 뗀 뒤 0.5초 사용 동작이 진행됩니다. 기본 괭이와 물뿌리개는 기존처럼 누르는 순간 사용 동작을 시작합니다.

충전 중에는 이동·방향 전환을 허용하며 현재 방향의 범위를 표시합니다. 0.5초에 도달하면 테두리가 1칸에서 3칸으로 늘어납니다. 버튼을 뗄 때 범위가 고정되고 사용 동작 동안 이동·장비 교체를 막습니다. 각 칸의 가능 여부를 초록·빨강으로 표시하고 시작·완료 시 개별 검사합니다. 중앙 칸이 막혀 있어도 유효한 옆칸은 처리합니다. 충전 범위는 밭 갈기에만 적용하며 모든 작물을 건너뜁니다. 기존 임시 수확은 짧은 1칸 사용으로 유지합니다.

임시 내구도 규칙은 성공한 사용 한 번에 1 소모입니다. 세 칸에 성공해도 1만 소모하며 마지막 내구도로도 전체 범위를 처리한 뒤 도구가 사라집니다. 전부 불가능하면 상태·내구도를 변경하지 않습니다.

충전 중 장비 선택·이동, 메뉴 열기, 구르기, 사망, 캐릭터 교체, 입력 취소나 창 포커스 상실은 충전을 취소합니다. 취소 후 들어오는 버튼 뗌 이벤트는 사용을 발생시키지 않습니다. 충전을 취소할 때 다른 시스템의 이동 잠금은 해제하지 않습니다.

`PeaceSign.Farming.ChargedHoe`는 Enhanced Input 누름·유지·뗌 이벤트, 충전/사용 시간 분리, 네 방향의 범위, 부분 성공과 전체 실패, 미리보기, 효과 직전 상태 변경, 작물 보호, 취소, 마지막 내구도와 저장 이관을 검증합니다. 물뿌리개의 강화 범위는 포함하지 않았습니다.

## 2차 강화 괭이

2026-10-20: `Hoe.Upgrade2`를 추가했습니다. 새 게임의 Hotbar 8번 칸에 임시 지급합니다. 버전 7 이하 저장에서는 8번, 다른 빈 Hotbar, 열린 가방의 빈 칸 순으로 보충합니다. 전부 가득 차면 별도의 지급 대기를 저장하고 빈 칸이 생길 때 한 번 지급합니다. 저장 버전은 8이며 기존 1차 괭이의 ID·내구도·지급 대기를 유지합니다. 지급을 완료한 도구는 내구도가 닳아 사라져도 불러오기로 재지급하지 않습니다.

짧게 누르고 떼면 앞 1칸, 0.5초 이상 누르고 떼면 전방 3×3칸에 사용합니다. 범위는 캐릭터 앞쪽 1~3줄과 좌우 한 칸씩이며 캐릭터가 서 있는 칸은 포함하지 않습니다. 3×3의 중심은 캐릭터의 두 칸 앞입니다. 충전 중 방향을 바꿀 수 있고 버튼을 뗄 때 범위를 고정합니다. 이후 0.5초 사용 동작과 이동·장비 교체 잠금이 적용됩니다.

9칸을 초록·빨강으로 각각 표시하고 효과를 적용할 때 다시 검사합니다. 장애물·물·이미 갈린 밭·작물·월드 바깥 칸은 건너뛰고 가능한 칸만 변경합니다. 한 칸이라도 성공하면 사용 한 번에 내구도 1을 소모하며, 마지막 내구도로도 전체 범위를 처리한 뒤 도구가 사라집니다. 충전 사용으로 작물을 제거하거나 수확하지 않으며, 짧은 1칸 사용의 임시 수확은 유지합니다.

범위는 아이템 정의의 `ChargedHoeDepth`로 구분합니다. 기본 괭이는 0, 1차는 1줄, 2차는 3줄입니다. 미리보기 액터는 필요한 수만큼 늘리고 작은 범위로 돌아갈 때 남는 액터를 숨겨 재사용합니다.

`PeaceSign.Farming.SecondHoe`는 실제 누름·뗌 입력, 별도 사용 시간, 네 방향의 9칸 범위, 미리보기 전환, 부분 성공·실패, 작물 보호, 월드 경계, 마지막 내구도와 버전 7 저장의 지급·중복 방지·가득 찬 가방 처리를 확인합니다.

`PeaceSign.Farming.FrontCellToolAction`은 우클릭 시작, 네 방향 및 대각선 방향, 지연 효과, 이동·장비·메뉴 잠금, 연속 입력, 사용 직전 상태 변경, 장비 제거·캐릭터 해제·죽음·강제 이동에 의한 취소, 물 주기, 임시 수확 및 테두리 메시를 확인합니다.
