# 임시 인벤토리 UI

9월 16일 기획서의 가방 배치와 이동 규칙을 확인하는 UMG 프로토타입입니다.
게임에서 I로 열고 I, Esc 또는 닫기 버튼으로 닫습니다. 싱글플레이에서는 메뉴를 열면 일시정지하고, 이 메뉴가 건 일시정지만 닫을 때 해제합니다.

갈색 슬롯 10열 × 5행 중 첫 10칸을 사용하고 나머지는 잠금 표시합니다. 샘플 괭이·씨앗·작물·목재·돌·물고기를 클릭하면 설명을 표시합니다. 드래그로 빈칸에 이동하거나 다른 아이템과 교환할 수 있습니다. 잠긴 칸이나 창 밖에 놓으면 원래 위치를 유지합니다. 이동 완료 전에는 데이터가 바뀌지 않습니다.

샘플은 실제 아이템 소유량, 수확 카운터, 씨앗 소비, 골드와 연결되지 않습니다. 창을 닫았다 열어도 배치는 유지되지만 새 플레이 세션에서는 초기화합니다. 확장 구매, 자동 중첩, 스택 분할, 사용·버리기, 장비창·툴바, 저장·사망 드롭은 포함하지 않습니다. 세계 시간 일시정지는 임시 싱글플레이 정책입니다.

## 아트 교체

`/Game/UI/WBP_Inventory`의 Class Defaults에서 Inventory > Art의 Slot Brush, Selected Slot Brush, Hover Slot Brush에 슬롯 이미지를 지정합니다. Preview Items의 각 Icon에 아이템 텍스처를 지정할 수 있습니다. 텍스처가 없으면 코드로 그린 임시 도트 아이콘을 사용합니다. 최종 슬롯 텍스처를 지정하면 기본 슬롯 내부 음영은 생략합니다.

현재 레이아웃은 C++에서 생성합니다. WBP의 디자이너 배치로 자동 대체되는 구조는 아닙니다. 전체 레이아웃을 아트 시안에 맞게 바꿀 때는 `PSInventoryWidget.cpp`의 레이아웃 생성 부분을 수정하거나 디자이너 기반 위젯으로 이관해야 합니다. 컨트롤러의 Inventory Widget Class로 다른 자식 클래스를 지정할 수 있습니다.

## 검증

`PeaceSign.Inventory.Preview` 자동화 테스트는 이동·교환 및 잠긴 칸 거부 후 수량 보존을 확인합니다. GPU가 있는 실행에 `-PSInventoryRender`를 추가하면 실제 UMG를 Saved/InventoryPreview.png 및 작은 화면 버전으로 렌더링합니다.
