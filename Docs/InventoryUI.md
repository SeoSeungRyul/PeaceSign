# 인벤토리 데이터와 UI

9월 16일 기획서의 가방 배치와 이동 규칙을 적용한 인벤토리입니다.
화면 아래에는 `1`부터 `0`까지 10칸의 Hotbar가 항상 표시됩니다. 게임에서 I를 누르면 Hotbar를 유지한 채 가방을 열고, I, Esc 또는 닫기 버튼으로 가방을 닫습니다. 싱글플레이에서는 가방을 열면 일시정지하고, 이 메뉴가 건 일시정지만 닫을 때 해제합니다.

Hotbar와 가방은 서로 독립된 물리 슬롯입니다. 새 게임은 Hotbar 10칸과 가방 10칸, 총 20칸을 사용할 수 있고 가방의 나머지 40칸은 잠금 표시합니다. 새 게임의 Hotbar에는 괭이 1개, 씨앗 24개와 낚싯대 1개가 들어갑니다. 단축키는 해당 Hotbar 칸에 실제 아이템이 있을 때만 그 아이템을 선택하며, 빈 칸을 선택하면 맨손이 됩니다.

I로 가방을 연 상태에서는 Hotbar와 가방 사이 또는 같은 영역 안에서 아이템을 드래그해 이동하거나 교환할 수 있습니다. 같은 작물 ID의 같은 아이템끼리는 최대 중첩 수량까지 합치며 초과 수량은 원래 슬롯에 남습니다. 잠긴 칸이나 창 밖에 놓으면 원래 위치를 유지합니다.

`UPSInventoryComponent`가 Hotbar 10칸, 가방 최대 50칸, 열린 가방 슬롯 수와 수량을 관리하는 유일한 데이터 원본입니다. UI는 이 컴포넌트를 표시하고 이동 요청만 전달합니다. 두 영역의 슬롯과 수량은 별도 `PeaceSignInventory` 저장 슬롯에 자동 저장되어 다음 플레이에도 유지됩니다. 예전 단일 인벤토리 저장 데이터는 첫 10칸을 Hotbar로, 이후 슬롯을 가방으로 옮겨 읽습니다.

파종은 현재 선택한 Hotbar 칸의 씨앗만 소비합니다. 다 자란 작물을 수확하면 같은 작물 ID의 수확물 1개가 가방에 들어가며, 획득 아이템이 Hotbar 빈칸을 자동으로 채우지는 않습니다. 가방에 자리가 없으면 작물은 밭에 남습니다. 골드, 확장 구매, 스택 분할, 사용·버리기, 별도 장비창과 사망 드롭은 아직 연결하지 않았습니다. 세계 시간 일시정지는 임시 싱글플레이 정책입니다.

## 아트 교체

`/Game/UI/WBP_Inventory`의 Class Defaults에서 Inventory > Art의 Slot Brush, Selected Slot Brush, Hover Slot Brush에 슬롯 이미지를 지정합니다. Item Icons에 아이템 텍스처를 지정할 수 있습니다. 텍스처가 없으면 코드로 그린 임시 도트 아이콘을 사용합니다. 현재 Hotbar도 같은 방식의 임시 아이콘을 사용합니다. 최종 슬롯 텍스처를 지정하면 기본 슬롯 내부 음영은 생략합니다.

현재 레이아웃은 C++에서 생성합니다. WBP의 디자이너 배치로 자동 대체되는 구조는 아닙니다. 전체 레이아웃을 아트 시안에 맞게 바꿀 때는 `PSInventoryWidget.cpp`의 레이아웃 생성 부분을 수정하거나 디자이너 기반 위젯으로 이관해야 합니다. 컨트롤러의 Inventory Widget Class로 다른 자식 클래스를 지정할 수 있습니다.

## 검증

`PeaceSign.Inventory.DataAndUI` 자동화 테스트는 Hotbar와 가방의 분리, 두 영역 사이 이동·교환·중첩, 가방 우선 획득, 선택한 Hotbar 슬롯의 소비, 잠긴 칸 거부, 이전 저장 데이터 변환, 저장 복원과 수량 보존을 확인합니다. GPU가 있는 실행에 `-PSInventoryRender`를 추가하면 가방 UMG를 Saved/InventoryPreview.png 및 작은 화면 버전으로 렌더링합니다.
